# Palm Cove Community Voices Wall – Version 2

## Upload to GitHub
1. Open the existing `palm-cove-community-voices` repository.
2. Replace `index.html` and upload `styles.css`, `quotes.js`, and `app.js` to the repository root.
3. Commit the changes to the `main` branch.
4. GitHub Pages will rebuild automatically. Refresh the published URL after one or two minutes.

## Files
- `index.html` – page structure
- `styles.css` – visual design
- `quotes.js` – 157 survey quotations
- `app.js` – rotation, filters and controls

## Google Sites
Embed the existing GitHub Pages URL. No change to the Google Sites embed URL is needed after updating these files.
